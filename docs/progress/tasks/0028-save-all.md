# 任务 0028：全部保存 + getContent 防丢数据加固

- 状态：✅ 落地并过 `pnpm check` + build/budget
- 里程碑：M2 · 负责人：Claude · 开工/收工：2026-06-04

## Why
- 多标签编辑后需一键存盘(每个编辑器都有的高频操作)。
- 分屏(0023)引入潜在丢数据风险:`getContent` 只读聚焦面板实例;聚焦分屏时读「仅存在于主面板的标签」会得空串 → 保存即覆盖为空。

## How
- **`App.getContent` 加固**:按「聚焦面板优先 → 另一面板回退」顺序取实例,任一面板挂载即返回真实内容,**绝不对已挂载标签返回空串**。同时修正单文件保存在跨面板场景的潜在误读。
- **`useEditorTabs.saveAll`**:并发写所有脏标签(主面板挂载全部标签,内容齐全),成功后一次性清脏 + 单条汇总 toast(不逐文件刷屏)。失败响亮报错(遵守 no-fallback)。
- **命令/快捷键**:命令面板「全部保存」;`Ctrl/⌘+⌥+S`。i18n `file.saveAll` / `file.savedAll`(count 复数)。

## 验证
- ✅ `pnpm check` 全绿;build + budget 首屏在预算内。
- ⏳ GUI 行为(多脏标签一键存、分屏聚焦下保存主面板标签不丢)待显示自验。

## 备注
此加固消除了 0023 已知限制中「分屏聚焦时保存可能误读」的丢数据隐患;同文件双面板「内容分叉」的限制仍在(两实例各自独立),save 仍以聚焦面板为准。
