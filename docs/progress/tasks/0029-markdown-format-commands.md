# 任务 0029：Markdown 格式化命令族（写作级 MD 护城河②）

- 状态：✅ 落地并过 `pnpm check`（含 5 单测）+ build/budget
- 里程碑：M3 · 负责人：Claude · 开工/收工：2026-06-04

## Why
写作级 Markdown 是差异化支柱②。常用格式化(粗体/斜体/标题/列表/引用)若靠记符号或翻菜单都慢。Jobs 准则:用**命令面板动词**而非满屏工具条按钮承载——保持「克制 + 非模态」。

## How
- **纯函数 `features/markdown/mdFormat.ts`**(全单测):
  - `toggleWrap(text, marker)`:行内环绕切换(粗体 `**`/斜体 `*`/行内码 `` ` ``/删除线 `~~`),已包裹则去除。
  - `toggleLinePrefix(text, prefix)`:行级前缀切换(标题/引用/无序列表),整段已有则去除。
  - `toggleOrderedList(text)`:逐行编号 / 去编号。
- **App 接线**:
  - `formatInline(marker)`:对每个选区切换环绕标记,`view.dispatch`(不静态导入 CM,守首屏红线)。
  - 行级项复用既有 `transformLines`(自动扩到整行 + 合并选区)。
  - 9 条命令(粗体/斜体/码/删除线/标题1/标题2/引用/无序/有序),**仅当聚焦文件为 Markdown 时进命令面板**(上下文相关,面板克制)。
- 双语 i18n `mdfmt.*`。

## 已知限制
- 「切换」为简单前后缀匹配:对 `**bold**` 执行斜体(`*`)会先剥外层 `*` → `*bold*`(与多数编辑器一致,可接受)。
- 行内命令对空选区成对插入标记,光标停在标记后(未自动置于中间);嵌套/跨段复杂场景留后续。
