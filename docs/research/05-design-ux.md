- 状态：✅ 完成（2026-06-02）

## 核心命题：世界级 UX 不是"长相"，是一份契约

> 编辑器必须让人感觉是**双手的直接延伸，用户永远不在等机器**。

## 关键发现

- **延迟即头条功能，且可度量**：Zed ~2ms 键入到像素 vs VS Code ~25ms，Electron 类 30–80ms。Nielsen 0.1s（100ms）= "瞬时/由我引起"阈值（Google RAIL 沿用为 <100ms 输入响应）。我们的目标：键入到上屏 < 16ms（60Hz 一帧），冲刺 < 8ms（Zed 级）。**用户感知"高级"的是延迟，不是功能数量。**
- **帧预算是硬数字**：120fps = 8.3ms/帧、60fps = 16.7ms/帧；Zed 渲染 < 4ms（GPU 整帧并行、无 GC、无合成器在路径上）。工程师必须把 8.3ms 当预算去 profile，**绝不在 UI 线程上阻塞 I/O 或布局**。
- **Goto Anything 是要克隆的即时模糊查找基线**：Sublime `Ctrl/Cmd+P` 一个栏搞定文件/符号(`@`)/行(`:`)/词(`#`)，子序列模糊匹配，数万文件项目仍每键瞬时响应。
- **命令面板是万能动词面（Raycast 血统）**：从"搜索"到"搜索+执行"，键盘优先，每个动作可达、可模糊搜、内联显示快捷键（面板自我教学）。满足 Nielsen #6（识别优于回忆）、#7（加速器）。
- **现代桌面设计语言 = 克制、暗色优先、柔和景深**（Linear/Raycast/Arc）：近单色 chrome、单一强调色用于 active/selected/focus、低对比边框、**代码是唯一高对比元素**。
- **无障碍是验收项，带精确数字**：WCAG 2.2 AA —— 正文 4.5:1、大字 3:1、非文本 UI 与图形对象 3:1（SC 1.4.11）、焦点指示器 3:1（SC 2.4.11）。每套主题在亮/暗下都须过。全键盘可操作、正确屏幕阅读器语义、永不消失的焦点环。
- **等宽字体**：2026 默认共识 = JetBrains Mono（专为代码、可变字重、真斜体、139 连字）。建议：**捆绑 JetBrains Mono 作默认，连字默认关**（divisive 且可能误导运算符），一键开关，允许换任意已装等宽。
- **启动要像"它本来就开着"**：冷启动 < 300ms、热启动 < 120ms、即时会话恢复（标签/光标/滚动/折叠/分屏）；首帧就显示可编辑内容，**启动转圈 = UX 失败**。
- **大文件是正确性/UX 阈值**：100MB/100 万行 < 1s 可滚动可编辑，高亮渐进流入，绝不冻结 UI 线程。
- **"高级感"微交互**：多光标即时增加且同步闪烁、零延迟同改；查找/替换增量计数 + 实时高亮 + regex 内联错误态 + 替换预览；像素级平滑动量滚动 + sticky scroll；标签/分屏拖拽有清晰落点、键盘驱动分屏。
- **动效语言**：只为保持空间连续性（面板开合、标签重排）；120–200ms、ease-out、无弹跳、**打字循环里绝不加动效**；完全尊重 `prefers-reduced-motion`。
- **空态与错误是教学，不是责备**：空编辑器 = 安静的快捷键速查表；错误用平白语言说"发生了什么 + 怎么恢复"，恢复动作一键可达；能用撤销就别用确认弹窗。

## 风险

- **Web 栈达 < 16ms（更别说 < 8ms）很难**：Zed 为此自研 GPU 框架（GPUI）。若不走原生/GPU，"延迟即产品"这条头条须在定架构前用**延迟原型**验证。
- 帧预算回归是无声的 → 需 CI 里有键入延迟 + 帧时自动化门禁，而非口号。
- 连字可能误导（`!=` vs `≠`、标识符里的 fi/fl）→ 默认关、opt-in。
- WCAG 2.2 仍用相对亮度法，APCA 尚非采纳标准 → 显式决定对比方法，别假设 APCA 合规算达标。
- 大文件/大项目易因 naive LSP 集成回归 → 懒/虚拟化解析、off-main 索引从一开始就在架构里。
- "极简 chrome"可能伤可发现性 → 用面板自教快捷键 + 安静空态速查 + 渐进披露，别让克制变成不可用。
- 允许任意用户主题 → 多数会过不了 AA → 需加载期对比度校验/警告。
- 跨平台 120fps 行为不同（Metal/DirectX/Vulkan + 不同合成器）→ 按平台处理空闲降频与 vsync 怪异。
