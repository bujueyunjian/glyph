## A. 十条设计准则

> ⭐ **第 0 条（北极星，凌驾全部）· 用户体验高于一切，且由我们引领**：我们替用户定义好体验、引领用户，**不无条件服从用户的要求/反馈**（Jobs：先于用户搞清他们将要什么）。但对**体验标准绝不妥协**——功能 / 工期 / 技术优雅 与 体验冲突时，砍前者、守体验高线。后面 10 条是这条的展开。

1. **延迟即产品** —— 没在一帧内上屏，就是 bug，不是"慢"。
2. **键盘即 API** —— 每个动作都可达且键盘更快；鼠标是可选项。
3. **一个栏去任何地方** —— Goto-Anything 查找（文件/符号/行/文本，前缀语法）+ 自我教学快捷键的命令面板。
4. **代码是唯一高对比的东西** —— 安静的近单色 chrome，单一强调色克制使用，对比度都给内容。
5. **显示内容，而非转圈** —— 恢复精确会话，首帧就画出可编辑文本。
6. **永不阻塞 UI 线程** —— I/O、解析、搜索、lint 全部 off-main；光标永远能动。
7. **动效只为定位** —— 120–200ms ease-out，绝不进打字循环，永远尊重 reduced-motion。
8. **生而无障碍** —— 每套主题过 WCAG 2.2 AA，全键盘可操作，真屏幕阅读器语义，焦点环永不丢失。
9. **撤销优于确认** —— 用可逆动作替代弹窗（Nielsen 用户控制/自由）。
10. **默认即设计决策** —— 出厂即美、快、可访问；连字默认关、暗色默认、合理键位。

## B. 性能即体验（硬 SLO，CI 门禁）

| 指标 | 目标 | 冲刺 |
|---|---|---|
| 冷启动到可交互 | < 300ms | < 200ms |
| 热启动 | < 120ms | —— |
| 键入到上屏 p99 | < 16ms（60Hz） | < 8ms（Zed 级） |
| 命令面板/查找 首结果 | < 50ms（5 万文件） | —— |
| 查找 每键过滤 | < 16ms（5 万文件） | —— |
| 滚动/交互帧 | 8.3ms@120fps / 16.7ms@60fps，渲染 < 4ms | —— |
| 打开 100MB/100 万行 | < 1s 到可滚动可编辑，高亮渐进 | —— |
| 空闲 CPU / 内存 | ~0% / 编辑器外壳低十位 MB | —— |

> 这些是承诺，不是愿望。**键入延迟与帧时必须进 CI 自动化门禁**——否则性能会随功能逐步腐烂（见 [`../research/05-design-ux.md`](../research/05-design-ux.md) 风险）。

## C. 视觉方向

### 排版
- **代码字体**：捆绑 **JetBrains Mono** 作默认（14px / 1.5 行高基线），**连字默认关**并提供一键开关；用户可换任意已装等宽（高级可选 Berkeley Mono / MonoLisa）。
- **UI 字体**：Inter / system-ui（团队 git-ai-studio 用 Geist，可沿用 Geist 保持品牌一致——待 [`../adr/`](../adr/) 决议）。

### 间距与密度
- **8px 栅格**（4px 半步）。
- 三档密度：Comfortable（行高 28px）/ Default（22px）/ Compact（18px）。

### 颜色与主题（已实现 token 化运行时切换，见 [ADR-0005](../adr/0005-theming-system.md)）
- **token 化语义模型**：`bg / surface / overlay`、`text / muted / subtle`、`accent`（后续补 `success / warn / error` 与各 syntax scope）。主题 = token map（数据），运行时写到 `documentElement` 的 CSS 变量。
- **内置主题（v1）**：`glyph-dark`（默认，柔和深色）/ `glyph-light`（浅色）/ `midnight`（纯黑）。左上角「视图 → 主题」切换，localStorage 持久化；编辑器主题随明暗跟随。
- 亮 + 暗主题均应过 AA（正文 4.5:1、非文本/焦点环 3:1）—— **加载期对比度校验器尚未实现（TODO）**。
- 近单色 chrome + 单一强调色。
- **主题插件 / 用户自定义主题**：提供同形 token map 即可接入（随插件系统 v2），加载期须过对比度校验。

### 图标与动效
- 单套 16px 线性图标，1.5px 描边，3:1 对比；**含义绝不只靠颜色**。
- 动效 120–200ms ease-out，仅定位用途，reduced-motion → 瞬时。

## D. 标志性微交互（8.3ms 预算花在这里）
- **多光标**：即时增加（Cmd/Ctrl-click + "选下一处"），所有 caret 同步闪烁，零延迟同改。
- **查找/替换**：增量匹配计数 + 文档内实时高亮、regex 内联错误态、替换预览。
- **滚动**：像素级平滑动量、亚像素文本、当前作用域 sticky scroll、设备允许则 120fps。
- **标签/分屏**：拖拽有清晰落点、键盘驱动分屏（如 `Cmd+\`）、focus-follows-keyboard。
- **空态**：安静的快捷键速查表（打开文件夹/命令面板/最近项目），非营销。
- **错误**：平白语言、"发生了什么 + 怎么恢复"、恢复一键可达；能用状态栏/内联 toast 就不弹模态。

## E. 与团队既有约定的衔接
- 复用 git-ai-studio 的栈：Tailwind v4 + shadcn/Radix + lucide + sonner + cmdk。
- **双语 UI（i18next）**：所有面向用户字符串走 `src/i18n/locales/{zh-CN,en}.json`，组件用 `useTranslation()`，新增字符串同时给 zh-CN + en。
